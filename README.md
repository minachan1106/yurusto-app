# ユルスト

体重・食事・運動・美容を「ゆるく」記録して、目標の体重に戻していくための自分用スマホアプリです。
完璧な数字より、目安で続けることを大事にしています。

- 公開URL：https://minachan1106.github.io/yurusto-app/
- 仕様：[SPEC.md](./SPEC.md)／開発のルール：[CLAUDE.md](./CLAUDE.md)

## 新しい端末で使うとき

1. iPhone の Safari で公開URLを開き、共有メニューから「ホーム画面に追加」
2. ホーム画面のアイコンから開く（Safariで開いたものとは記録の保存場所が別です）
3. 設定 → 「目標とからだ」で、目標体重の範囲・体脂肪率の目標・身長・年齢・性別・ふだんの活動量を入れる
   - 1日の目安（kcal・PFC）は自動で決まります
4. 設定 → 「Claude」で APIキーを入れる（Anthropic Console で発行。サブスクとは別の従量課金です）

## 毎日の使い方

| やりたいこと | 操作 |
| --- | --- |
| ごはん・コスメ・Uberの注文画面を記録 | ホームの「写真・スクショで記録」（または「カメラで撮る」「コピーした画像を貼る」）→ 選ぶだけで保存。間違えたら「取り消す」 |
| 文章で記録 | 記録する（真ん中の＋）に「昼にパスタ」などと書いて「記録する」。前に食べたものだけなら「ヨーグルト2個、パスタ半分」のように書くと、APIを使わずに計算するよ |
| 体重 | 朝のホームで、前回の近くの数字をタップ（ほかの数字は「ほか」） |
| 歩数 | ショートカット「ユルスト歩数」を実行（自動にもできる）→ ホームの「歩数を取り込む」か記録する（真ん中の＋）の「ヘルスケアから取り込む」。プルダウンやスクショでもOK |
| 運動 | 記録する（真ん中の＋） → 「いつもの」をタップ。ほかは「ほかの運動を選ぶ」から種目と回数を選んで「記録する」 |
| 間違えて保存した | 保存のあとに出る「取り消す」（結果カードかトースト） |
| いつも食べるもの | ホームの「いつものメニュー」をタップ（時間帯によく食べるものが出る。ほかは「ほか」） |
| 過去の日の記録 | 記録する（真ん中の＋）の上の「記録する日」を変えてから記録 |
| 記録の評価をもらう | 履歴タブの「Claudeにレビューしてもらう」で期間と観点を選ぶ |
| コスメの気持ちを残す | 美容・ファッション → コスメ → アイテムをタップ →「いい感じ」「リピしたい」などをタップ（ひと言は任意）。状態（使用中・ストック・お休み・使い切り）もここで |
| 着たい服を詳しくする | 美容・ファッション → ファッション → 服をタップ →「商品のスクショで詳しくする」 |
| 商品名を正式名に揃える | 美容タブの「商品名をチェック」→ 候補を確認して「選んだものを直す」（ネット検索も選べる） |
| 着たい服の目安 | ZOZOなどの商品ページやサイズ表のスクショを「記録する」に入れる → ホームに「あと約◯kg・約◯週間」が出る |
| 見返す | 履歴タブ（食事・運動・からだ・美容・メモで切り替え）。「カレンダー」で月ごとに見て、日付をタップ |
| PFCのバランス | ホームの「食事（概算）」カード（7日／14日） |
| ホームからさっと記録 | ホームのいちばん上のボタン（写真・体重・いつもの運動・歩数）。間違えたらトーストの「取り消す」 |
| 量を変える | 履歴で食事をタップ →「量を変える ×0.5〜×3」→ 保存 |
| 直す・消す | 履歴タブで行をタップ。「Claudeで直す」に「2枚分だった」などと書けば計算し直します |
| 前の記録を言葉で直す | 記録する（真ん中の＋）に「昨日のパンケーキ、2枚だった」と書いて「記録する」→ 修正内容を確認して反映 |

- いつものメニュー／いつもの運動は、履歴タブで食事・運動をタップして「登録」します。
- ホームには「今日」の摂取・消費（概算）、体重と体脂肪率（推定）の推移、ご褒美ごはんの残り回数、Claude のコメントが出ます。

## データとアプリの更新

- 記録はこの端末のブラウザの中にだけ保存されます。ときどき 設定 → 「データとアプリ」 → エクスポート でバックアップしてください。
- 新しいバージョンが公開されると、アプリを開いたときに上に「更新する」が出ます。設定の「更新を確認」でも確かめられます。

## プライバシー

このリポジトリは公開です。体重や目標などの個人の値はコードやドキュメントに書かず、アプリの設定画面で入力します。
