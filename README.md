# ユルスト

体重・食事・運動・美容を「ゆるく」記録して、目標の体重に戻していくための自分用スマホアプリです。
完璧な数字より、目安で続けることを大事にしています。

- 公開URL：https://minachan1106.github.io/yurusto-app/
- 仕様：[SPEC.md](./SPEC.md)／開発のルール：[CLAUDE.md](./CLAUDE.md)

## はじめに（1回だけ）

1. iPhone の Safari で公開URLを開き、共有メニューから「ホーム画面に追加」
2. ホーム画面のアイコンから開く（Safariで開いたものとは記録の保存場所が別です）
3. 設定 → 「目標とからだ」で、目標体重の範囲・体脂肪率の目標・身長・年齢・性別・ふだんの活動量を入れる
   - 1日の目安（kcal・PFC）は自動で決まります
4. 設定 → 「Claude」で APIキーを入れる（Anthropic Console で発行。サブスクとは別の従量課金です）

## 毎日の使い方

| やりたいこと | 操作 |
| --- | --- |
| ごはん・コスメ・Uberの注文画面を記録 | 投げ込み → 「＋ 写真・スクショを追加」 → 「記録する」 → 確認して保存 |
| 文章で記録 | 投げ込みに「昼にパスタ」などと書いて「記録する」 |
| 体重 | 投げ込み → 体重のプルダウンを選んで「保存」 |
| 歩数 | ショートカット「ユルスト歩数」を実行（自動にもできる）→ 投げ込みの「ヘルスケアから貼り付け」。プルダウンやスクショでもOK（手順は 設定 →「歩数」） |
| 運動 | 投げ込み → 「いつもの」をタップ、または種目と回数をプルダウンで選んで「記録する」 |
| いつも食べるもの | 投げ込み → 「いつものメニュー」をタップ（多いときは「ほかを探す」） |
| 過去の日の記録 | 投げ込みの上の「記録する日」を変えてから記録 |
| 着たい服の目安 | ZOZOなどの商品ページやサイズ表のスクショを「記録する」に入れる → ホームに「あと約◯kg・約◯週間」が出る |
| 見返す | 記録タブ（食事・運動・からだ・美容・メモで切り替え） |
| 直す・消す | 記録タブで行をタップ。「Claudeで直す」に「2枚分だった」などと書けば計算し直します |
| 前の記録を言葉で直す | 投げ込みに「昨日のパンケーキ、2枚だった」と書いて「記録する」→ 修正内容を確認して反映 |

- いつものメニュー／いつもの運動は、記録タブで食事・運動をタップして「登録」します。
- ホームには「今日」の摂取・消費（概算）、体重と体脂肪率（推定）の推移、ご褒美ごはんの残り回数、Claude のコメントが出ます。

## データとアプリの更新

- 記録はこの端末のブラウザの中にだけ保存されます。ときどき 設定 → 「データとアプリ」 → エクスポート でバックアップしてください。
- 新しいバージョンが公開されると、アプリを開いたときに上に「更新する」が出ます。設定の「更新を確認」でも確かめられます。

## プライバシー

このリポジトリは公開です。体重や目標などの個人の値はコードやドキュメントに書かず、アプリの設定画面で入力します。
